## API 이미지의 촬영 방법

주요 API 이미지는 `capture-evidence.mjs`가 제공하는 검증용 화면의 실제 브라우저 캡처입니다. 이 화면은 같은 서버의 `/api/favorites`와 `/api/favorite-count`에 실제 fetch 요청을 보내 URL·HTTP 상태·응답 JSON을 표시합니다. 브라우저 주소창을 이미지에 합성한 것이 아니며, 원본 JSON 직접 방문 캡처도 `*-raw.png`로 함께 포함했습니다.

검증 화면의 `/__evidence` 경로는 임시 서버 사본에만 추가됩니다. 제출 `server.js`는 필수 API만 포함하며 테스트 항목은 없습니다. `node capture-evidence.mjs`는 8건, `node capture-evidence.mjs --nine`은 테스트 항목 id 30을 추가한 9건으로 실행합니다. 실행할 때 4000 포트는 비어 있어야 하며 종료는 Ctrl+C입니다.

## 검증 범위와 데이터 보호

Firebase Console의 MFA 설정은 변경하지 않았습니다. 이전 영화 수업 프로젝트의 기존 로컬 설정과 사용자가 제공한 TMDB 토큰으로 앱을 실행했습니다. 실제 Google 로그인, Firestore 읽기/쓰기, 새로고침 및 빈 메모 복원을 확인했습니다. 검증용으로 추가한 찜은 제거했으며 기존 데이터는 보존했습니다.

네트워크 강제 차단·보안 규칙 변경 테스트, 프로덕션 서버 전체 브라우저 재검증, 공개 배포는 수행하지 않았습니다. Firebase 보안 규칙을 공개로 바꾸거나 새로 배포하지 않았습니다.

제출 ZIP에는 비밀값·실제 환경 설정·사용자 UID가 포함된 로그·node_modules·.next·npm 캐시·임시 서버 파일을 넣지 않았습니다. 빈 `.env.example`은 포함했습니다. 재실행 시 본인 설정을 `.env.local`에 입력해야 합니다.
